# Fast Gallery – BI Dashboard

Static BI dashboard for Fast Gallery (Overview, Funnel, Installations, Ready Galleries). Hosted on GitHub Pages.

**Important:** The `index.html` in this folder is a placeholder. Follow **Step 1** below so your full dashboard is used on GitHub Pages.

---

## Publish on GitHub Pages

### 1. Use the correct `index.html`

Use your **full** dashboard as the main page:

- Copy **`fast_gallery_dashboard12.html`** from your Desktop into this folder.
- Rename the copy to **`index.html`** (replace the existing `index.html` in this folder).

So this folder should contain:

- **`index.html`** – your full dashboard (the same content as `fast_gallery_dashboard12.html`, just renamed).
- **`README.md`** – this file.

### 2. Create the GitHub repository

1. Go to [github.com/new](https://github.com/new).
2. Repository name: **`fast-gallery-dashboard`** (or any name you prefer).
3. Choose **Public**.
4. Do **not** check “Add a README” (you already have files).
5. Click **Create repository**.

### 3. Upload the files

1. On the new repo page, click **“uploading an existing file”** (or **“Add file” → “Upload files”**).
2. Drag and drop:
   - **`index.html`** (the renamed dashboard)
   - **`README.md`** (optional)
3. Click **Commit changes**.

### 4. Turn on GitHub Pages

1. In the repo, go to **Settings**.
2. In the left sidebar, click **Pages** (under “Code and automation”).
3. Under **“Build and deployment”**:
   - **Source:** **Deploy from a branch**
   - **Branch:** **main** (or **master**)
   - **Folder:** **/ (root)**
4. Click **Save**.

### 5. Your live URL

After 1–2 minutes, the site will be available at:

**`https://<your-username>.github.io/fast-gallery-dashboard/`**

Replace `<your-username>` with your GitHub username. If you used a different repo name, use that instead of `fast-gallery-dashboard`.

---

## Updating the dashboard

Edit your local `index.html`, then in the repo:

1. Open **`index.html`** on GitHub.
2. Click the pencil icon (Edit).
3. Paste the new content and commit.

The updated dashboard will appear at the same URL after a short delay.
